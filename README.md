КАК ПОЛУЧИТЬ API ТОКЕН ДЛЯ РАБОТЫ БОТА:
1. В тг найти бота "BotFather" и запустить его. !!!РЯДОМ С НАЗВАНИЕМ БОТА ДОЛЖНА БЫТЬ ГАЛОЧКА!!!
2. Написать команду "/newbot"
3. Придумать и написать имя и username бота (username должен оканчиваться на _bot или Bot)
4. Бот отправит HTTP API токен. Он выглядит как рандомные буквы и цифры.
5. Вставить токен в поле "TOKEN" для токена.
6. Готово! Бот работает!
